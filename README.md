Exactly one emoji: 🌻, the sunflower — warm at first glance, readable the same friendly way by a stranger of any age or background, and chosen rather than the default first smiley. The emoji lives in `entry.txt` (a single Unicode code point, 4 UTF-8 bytes, no newline); `main.py` copies it byte-for-byte to the output as `/output/entry.txt`. Candidates were gathered from several models and the pick was made against the bounty's published judge brief (see WINNER notes in the build record: the house judge route was credit-exhausted on the day, so the final pick is the builder's own best candidate, documented as such).

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
